# Noduct feedback

Report problems, suggest improvements and follow new versions of [Noduct](https://noduct.app). Noduct's file tools for PDFs, images and everyday tasks run in your browser, so your files are never uploaded.

This repository holds no code. It is the public place where people who use Noduct can talk to the team.

## How to help

| You want to… | Go to |
| --- | --- |
| Tell us something is broken | [Report a problem](../../issues/new?template=bug_report.yml) |
| Make an existing tool better | [Suggest an improvement](../../issues/new?template=improvement.yml) |
| Ask for a tool that doesn't exist yet | [Request a tool](../../issues/new?template=tool_request.yml) |
| Share an open idea or ask a question | [Discussions](../../discussions) |
| See what changed in each version | [Releases](../../releases) |
| Report a security issue | [Security policy](SECURITY.md). Please don't open a public issue. |

The quickest way to report a problem is the **Feedback** page on the site, which you can reach from the footer of any Noduct page. It fills in the tool, the version and your language for you, then opens the form here.

## Before you post

- **Everything here is public.** Anyone can read what you write.
- **Never attach your documents.** No PDFs, scans, IDs, contracts or bank statements, not even "just to show the problem". Describe the file instead: its size, number of pages, and where it came from.
- **Screenshots are welcome.** Use *Prepare a screenshot* on the Feedback page first. It removes hidden data such as location from the image and lets you cover anything private, all inside your browser.
- **Videos:** a screen recording works better than a phone video. Watch it before attaching and make sure nothing personal shows.
- Write in English, Portuguese or Spanish, whichever you prefer.

## What happens next

1. A new issue is labeled `needs-triage`.
2. We confirm the problem or idea, ask for details if needed, and label it.
3. When a fix or a new feature ships, it shows up in the next [release](../../releases) with the version number you'll see in the site footer.

We follow a [code of conduct](CODE_OF_CONDUCT.md). Spam and abusive posts are closed and their authors may be blocked.
